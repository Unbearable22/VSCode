# Projects

Архив всех найденных сохранившихся сайтов Codespace на 20 октября 2026 года. Это хранение исходников, не публикация сайтов.

- [ЛАД](./ЛАД/) — static-site
- [Контур](./Контур/) — static-site
- [Северная линия](./Северная%20линия/) — static-site
- [Спектр пространства](./Спектр%20пространства/) — static-site
- [Синтетическая студия](./Синтетическая%20студия/) — technical-fixture
- [MarginTools](./MarginTools/) — full-stack-source

В папке каждого сайта находятся файлы и `previews/`. Различающиеся исторические снимки статических сайтов — в `versions/`; побайтовые дубликаты объединены. Не все версии успешно прошли QA. Отсутствующие или ранее удалённые исходники восстановить из Codespace невозможно.

Конфиденциальные ТЗ, очереди заданий, авторизация, токены, базы, зависимости и временные сборки не включены. MarginTools требует установки зависимостей и собственной конфигурации; статические сайты можно открыть локальным HTTP-сервером. Превью не являются доказательством текущей функциональности.
