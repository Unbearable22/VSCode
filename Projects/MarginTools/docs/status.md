Профиль Amvera принудительно задаёт защищённый режим, HTTPS APP_URL, локальное хранилище с явным разрешением и отключение оплаты. При отсутствии DATABASE_URL или реквизитов staging запуск блокируется. Перед HTTP выполняются prisma migrate deploy и идемпотентный seed; migrate reset не используется.

Истории GitHub и начальной конфигурации Amvera объединены без force push. Origin GitHub сохранён; Amvera использует отдельный remote. В репозитории нет секретов, пользовательских файлов, дампов, зависимостей и сборок. Список исходников: [source-files.txt](source-files.txt).

## Что реализовано

1. Публичные калькуляторы маржи, наценки, цены продажи, НДС, скидки и безубыточности; общий модуль десятичной арифметики.
2. Регистрация, сессии, кабинет и сохранённые расчёты.
3. Сделки с несколькими позициями, импортом табличных данных и сопоставлением колонок, учётом расходов и экспортом XLSX.
4. Коммерческие предложения: отдельные версии, PDF с кириллицей, публичные ссылки с ограничением срока и отзывом. Закупка, прибыль и внутренние комментарии исключены из клиентской версии.
5. Каталог товаров, клиенты, реквизиты компании и оформление документов.
6. Серверные тарифные лимиты, сохранение данных при снижении тарифа и идемпотентный тестовый платёжный адаптер.
7. Админка для управления продуктом, тарифами, шаблонами, знаниями и обращениями; журнал изменений, аналитика и очередь уведомлений.
8. Telegram-бот: команды кнопками с эмодзи, оформленные ответы, пошаговые расчёты без ИИ, безопасная привязка и выбор КП для отправки PDF.
9. ИИ-инструменты с серверными проверками доступа, базой знаний и внутренними лимитами. Подключение реального провайдера ещё требуется.

## Что ещё требуется

- Провести полный рабочий сценарий именно на Amvera: регистрация, сделка, КП, PDF, ссылка и её отзыв, каталог, административный доступ.
- Проверить сохранность файлов и данных после перезапуска Amvera и настроить регулярные резервные копии PostgreSQL и /data/private.
- Развернуть Telegram-бота отдельным процессом с общей базой и публичным APP_URL. Локальное окружение бота ранее использовало localhost; после публикации сайта оно не обновлялось в рамках этих работ. Проверить реальный диалог, привязку и доставку PDF.
- Подключить ИИ: AI_API_KEY, AI_BASE_URL, AI_MODEL и оценку стоимости. Сейчас меню и расчёты бота работают без ИИ; агент проверен тестовым HTTP-адаптером.
- Подключить почту для восстановления пароля. До настройки MAIL_WEBHOOK_URL восстановление сообщает о недоступности.
- Приватное S3 не подключено. Для тестовой Amvera используется разрешённый постоянный диск; обычный production по умолчанию продолжает требовать S3.
- После обновления Amvera повторить визуальную приёмку PDF, скачав файл заново. Ранее скачанные файлы не изменяются. Восстановление S3 пока не проверено.
- Предоставить и утвердить юридические сведения, контакты и реквизиты владельца.
- Реальные платежи подключать только после отдельного разрешения, выбора провайдера и подготовки юридических условий.

Ближайший порядок: приёмка сценария на Amvera → резервные копии и проверка перезапуска → отдельный Telegram-бот → почта и ИИ. Коммерческий запуск рассматривается отдельно.
