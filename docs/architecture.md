# Архитектура

Next.js обслуживает русскоязычный интерфейс и API. PostgreSQL хранит владельцев рабочих пространств, расчёты, сделки, неизменяемые версии КП, ссылки, тарифы и журнал. Prisma использует адаптер pg. Telegram запускается отдельным процессом.

Общие пакеты: `calculations` (Decimal.js), `contracts` (Zod), `database` (Prisma, сессии и бизнес-операции), `billing` (лимиты и тестовый адаптер), `config` (начальные тарифы и статьи), `ai-agent` (разрешённые инструменты). Сайт и бот используют одни расчёты и операции сохранения.

Сессия: случайный токен в HttpOnly cookie, в базе только SHA-256 токена. Пароли хешируются scrypt. Каждый приватный API получает владельца из сессии и ограничивает запрос рабочим пространством. Изменения с другого Origin отклоняются. Ограничение запросов хранится в PostgreSQL. Административные действия требуют роли admin и записываются в AuditLog.

Лимиты и создание записей выполняются под блокировкой Workspace. Тестовая оплата обрабатывается в транзакции, событие имеет уникальный идентификатор; повторная обработка завершённого платежа не продлевает подписку. Реального адаптера и webhook провайдера пока нет.

ProposalVersion хранит разрешённый клиентский снимок без закупки, прибыли и комментариев. ShareLink привязан к версии, ограничен сроком и отзывается. PDF формируется на сервере с локальным кириллическим шрифтом. Логотипы хранятся в приватном S3; в разработке доступно локальное хранилище.

ИИ обращается к совместимому HTTP API через разрешённые функции. Владелец определяется сервером по TelegramAccount. Есть дневной лимит вызовов и журнал токенов с оценкой стоимости. Без ключей или при ошибке ИИ работают команды, меню и детерминированный расчёт. Очередь Telegram-уведомлений обрабатывается ботом каждые 30 секунд с повторными попытками.
