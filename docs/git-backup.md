## Место на диске

На момент диагностики: диск 32 ГБ, занято около 29 ГБ (98%), доступно 736 МБ. Исходники проекта без зависимостей и сборок занимают около 1,5 МБ. Все оценки ниже приблизительные.

| Кандидат на последующую очистку | Объём | Как воспроизвести |
| --- | --- | --- |
| node_modules/ | 965 МБ | npm ci, npm run db:generate |
| apps/web/.next/ | 210 МБ | npm run dev или npm run build |
| ~/.npm/_cacache/ | 1,2 ГБ | npm загрузит пакеты повторно |
| ~/.cache/ms-playwright/ | 681 МБ | npx playwright install chromium |
| ~/.cache/prisma/ | 23 МБ | npm run db:generate |
| test-results/ | 8 КБ | npm run test:e2e |
| Docker build cache | 6,13 ГБ всего; 3,87 ГБ reclaimable | Повторная Docker-сборка |
| Неиспользуемые образы MarginTools | Около 3,87 ГБ уникальных слоёв | Сборка соответствующего Dockerfile |

Оценки образов и build cache могут пересекаться из-за общих слоёв; их нельзя просто складывать. Кандидаты вне Docker дадут примерно 3 ГБ. Кэш Copilot не включён в список: состав и связь с данными авторизации не проверены.

Сохранить: Docker volume docker_postgres_data (около 103 МБ), все остальные volumes, PostgreSQL, data/private, PDF, дампы и резервные копии, .env, файлы авторизации, .git. Не применять docker volume prune или docker system prune --volumes. Перед разрешённой очисткой воспроизводимых данных остановить использующие их процессы и повторно проверить список. В рамках этой задачи очистка не выполняется.
